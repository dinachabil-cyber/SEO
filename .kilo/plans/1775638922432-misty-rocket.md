# Calendar Feature Implementation Plan

## Overview
Implement a calendar feature for displaying and managing events, with public-facing calendar views and admin CRUD operations.

## Prerequisites Analysis
- **Event entity**: Already exists at `src/Entity/Event.php` with all required fields
- **Bundle manager**: Composer (no package.json - pure PHP/Symfony backend)
- **Styling**: Bootstrap 5.3
- **Routing**: Attribute-based (`#[Route(...)]`)
- **Forms**: Symfony Form component

## Phase 2: Controller & Routes

### 2.1 Create CalendarController
Path: `src/Controller/CalendarController.php`

Routes:
| Path | Name | Description |
|------|------|-------------|
| `/calendar` | `calendar_index` | List view (current month) |
| `/calendar/{year}/{month}` | `calendar_month` | Monthly view (e.g., /calendar/2026/04) |
| `/calendar/{slug}` | `calendar_show` | Event detail page |

Controller pattern (following existing conventions):
```php
#[Route('/calendar', name: 'calendar_')]

class CalendarController extends AbstractController
{
    #[Route('/', name: 'index')]
    public function index(EventRepository $repo): Response
    
    #[Route('/{year}/{month}', name: 'month')]
    public function month(int $year, int $month, EventRepository $repo): Response
    
    #[Route('/{slug}', name: 'show')]
    public function show(Event $event): Response
}
```

### 2.2 Create EventRepository
Path: `src/Repository/EventRepository.php`

Methods needed:
- `findByMonth(int $year, int $month, ?Site $site): array`
- `findUpcoming(?Site $site, int $limit = 10): array`
- `findBySlug(string $slug): ?Event`

## Phase 5: SEO Optimization

### 5.1 Event Detail Page SEO
In `CalendarController::show()`:
- Set `<title>`: `{$event.title} | {$site.companyName}`
- Set `<meta description>`: Truncate description to 160 chars

### 5.2 Structured Data (JSON-LD)
Add to `templates/calendar/show.html.twig`:
```twig
{% set schema = {
    "@context": "https://schema.org",
    "@type": "Event",
    "name": event.title,
    "description": event.description,
    "startDate": event.startAt|date('c'),
    "endDate": event.endAt|date('c'),
    "location": event.location
} %}
<script type="application/ld+json">{{ schema|json_encode }}</script>
```

### 5.3 Monthly View Indexable URLs
- `/calendar/2026/04` - Should be indexable
- Add internal links to event detail pages

### 5.4 Sitemap Integration
Create or extend existing sitemap:
- Add monthly archive URLs
- Add event detail URLs
- File: `src/Controller/SitemapController.php` or extend existing

## Phase 6: Admin Panel

### 6.1 CRUD Controller
Path: `src/Controller/Admin/EventController.php`

Routes:
| Path | Name | Description |
|------|------|-------------|
| `/admin/event` | `admin_event_index` | List all events |
| `/admin/event/new` | `admin_event_new` | Create new event |
| `/admin/event/{id}/edit` | `admin_event_edit` | Edit event |
| `/admin/event/{id}/delete` | `admin_event_delete` | Delete event |

### 6.2 Form Type
Path: `src/Form/EventType.php`

Fields:
- `title` (TextType)
- `description` (TextareaType)
- `startAt` (DateTimeLocalType)
- `endAt` (DateTimeLocalType)
- `location` (TextType, optional)
- `slug` (TextType, with unique validation)

### 6.3 Templates
Path: `templates/admin/event/`
- `index.html.twig` - Table list with filters
- `new.html.twig` - Create form
- `edit.html.twig` - Edit form

### 6.4 Duplicate Events Feature
Add "Duplicate" button that:
- Copies event with new title: "{original} (Copy)"
- Opens edit form with pre-filled data

## Phase 7: Security & Permissions

### 7.1 Access Control
- Public routes: Allow anonymous access
- Admin CRUD: Require `ROLE_ADMIN` or event ownership

### 7.2 Site Association
- Events must be associated with a Site
- Filter events by current user's sites (owner-based)

---

## Phase 8: Caching & Performance

### 8.1 HTTP Caching
Add cache headers to public routes:
```php

```

### 8.2 Response Caching
Use Symfony HttpCache or Twig cache blocks for calendar grids
